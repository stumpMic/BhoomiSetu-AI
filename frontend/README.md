# BhoomiSetu AI — Frontend Web Application

React 18 + Vite + Tailwind CSS portal for decision makers, land acquisition officers, and landowners.

## Setup & Running

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build for production
npm run build
```

## Mock API Mode
If the backend is not running, enable contract mock mode in `.env`:
```
VITE_USE_MOCK_API=true
```
This serves responses directly from `contracts/examples/`.
